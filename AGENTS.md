# GitHub Repository Code Explainer

## Project Goal

Build a local GenAI application that accepts a public GitHub repository URL
and generates a simple-language explanation of the repository.

## Architecture

GitHub URL
→ GitPython
→ Repository Processing
→ Relevant File Detection
→ Code Extraction
→ Ollama
→ FastAPI
→ Streamlit

## Technology Stack

- Python
- FastAPI
- Pydantic
- Uvicorn
- GitPython
- Ollama
- Streamlit
- python-dotenv
- Qwen3.5:9b

## Important Rules

- The explanation must be generated by the local Ollama model.
- Never hard-code repository explanations.
- Never execute code from cloned repositories.
- Never run npm scripts, package scripts, setup.py, binaries, or executables from cloned repositories.
- Only clone and read repository files.
- Do not add LangChain, vector databases, embeddings, Docker, authentication, or unnecessary frameworks unless explicitly requested.
- Keep the architecture simple and understandable for a BCA project/viva.
- Do not modify files outside this project directory.
